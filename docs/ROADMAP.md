# Delivery roadmap

## Implemented in reading pilot 0.2
- Short, attributed Greek excerpt from PHerc. 1667 XVII.1–6.
- Separate project English working translation and Modern Reading (both AI-assisted drafts).
- Greek + English default; Modern Reading opt-in.
- Phrase highlighting, mobile language switch, size and theme controls.
- Source and rights disclosure, explicit excerpt boundaries.
- Scroll/edition/passage IDs and edition-specific copied links.
- SHA-256 dependencies: changed Greek flags translations and blocks unchecked release.
- Node checks before deployment; only site files deployed.
- Draft permission inquiry, not sent.

## Next editorial gate
- Send permission inquiry only after sender/recipient and authorization are settled.
- Confirm source-asset licensing and obtain specialist review.
- Extend the genuine text sample, preserving uncertainty and missing context.
- Do not republish the complete scholarly translation before permission is established.

## Next technical work
- Real HTTP/device and assistive-technology testing in addition to local offline checks.
- Accessible reader evaluation with non-specialist readers.
- TEI/EpiDoc import profile and a generated site architecture when content grows.
- Immutable release enforcement and a user-facing revision comparison (not yet implemented).
- Papyrus image links/crops only when rights and coordinates are verified.

## Out of scope
A generic ancient-text catalogue, new CT processing, invented reconstructions presented as ancient words, or a claim that this pilot is a completed scholarly edition.
