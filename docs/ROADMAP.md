# Delivery roadmap

## Phase 1 — deployable prototype (current)
- GitHub Pages Actions deployment workflow
- Reader with Greek and English visible by default
- Optional Modern Reading panel
- Structured scroll manifest with edition IDs
- Explicit placeholders; no unlicensed third-party content

## Phase 2 — verified vertical slice
- Clarify exact permissions for PHerc. 1667
- Import one short verified passage, with uncertainty markers
- Draft a close English working translation and a separately marked modern reading
- Provide provenance and a layperson-friendly explanation
- Test mobile usability and accessibility

## Phase 3 — living editions
- Stable passage permalinks
- Revised decipherments and dependency-aware translation review
- Second scroll fixture and automated schema validation
- Evidence links and images only where rights and coordinates are verified

## Out of scope
- General ancient-text reading platform
- New CT unwrapping or ink-detection models
- Unverified reconstructions presented as ancient text
